## About Me

Senior Software Engineer with **5 years of experience** building **real-time, safety-critical systems** for the Oil & Gas industry. Worked **onsite in the United States**, collaborating directly with Halliburton engineers and enterprise partners including Aramco, ExxonMobil, and PetroVietnam.

## Experience

### FPT Software &nbsp;·&nbsp; Senior Software Engineer &nbsp;`2021 – Present`

**iDOS — Integrated Design of Service** · Halliburton &nbsp;`2024/03 – Present`
> A digital workflow for collaborative well planning across multiple product service lines, integrated with iEnergy® Cloud and DecisionSpace 365.

- Built **NestJS** backend services for well planning (validation, synchronization, automation), supporting hundreds of concurrent engineering sessions
- Developed interactive **Angular** components, reducing manual review cycles by ~30%
- Designed and optimized **PostgreSQL** schemas handling millions of records with strong transactional integrity
- Integrated **Kafka** event streaming with near real-time latency (&lt;1s)
- Maintained 80%+ test coverage with **Jest**

**RTWE — Real Time Well Engineering** · Halliburton &nbsp;`2021/09 – 2024/03` &nbsp;
> Real-time features for risk prediction, drill bit tracking, and geological visualization.

- Built real-time **Angular** dashboards monitoring drilling parameters (torque, drag, pressure, ROP)
- Developed **Node.js & Python** services processing thousands of telemetry events per second
- Implemented **Kafka + WebSocket** pipelines with sub-second latency
- Developed anomaly detection algorithms for drill bit and well stability
